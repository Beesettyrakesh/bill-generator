# Project Brief: Bill Generator

## Project Overview

The Bill Generator is a Next.js web application designed to streamline the billing process for power system companies. It enables users to generate standardized bills for multiple branches across different companies, with customized templates based on branch-specific requirements.

## Core Purpose

To automate and standardize the billing process for diesel generator usage across multiple branches of power system companies, reducing manual effort and ensuring consistency in bill generation.

## Key Goals

1. **Streamline Bill Generation**: Provide a user-friendly interface to quickly generate bills for different branches
2. **Ensure Accuracy**: Automatically calculate billing amounts based on predefined consumption rates and user inputs
3. **Support Multiple Templates**: Accommodate different billing formats (hours-based, minutes-based, start/end reading-based)
4. **Enable Batch Processing**: Allow users to queue multiple bills for batch download
5. **Maintain Consistency**: Ensure all generated bills follow company-specific templates and formats

## Target Users

- Administrative staff responsible for billing at power system companies
- Branch managers who need to generate bills for diesel generator usage
- Finance department personnel who process and distribute bills

## Core Functionality

1. **Branch-specific Bill Generation**: Generate bills tailored to each branch's specific requirements
2. **Automatic Calculations**: Calculate total amounts based on hours/minutes of usage and current fuel prices
3. **Document Generation**: Create downloadable DOCX files with all required billing information
4. **Batch Processing**: Select and download multiple bills simultaneously
5. **Input Validation**: Ensure all required fields are properly filled before bill generation

## Success Criteria

1. Reduced time spent on manual bill generation
2. Elimination of calculation errors in billing
3. Consistent formatting across all generated bills
4. Ability to handle all branches and their specific billing requirements
5. User-friendly interface that requires minimal training
